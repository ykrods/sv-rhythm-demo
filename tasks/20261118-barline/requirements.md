# requirements: barline

## 目的
Play 画面で、曲の小節の区切りを示す線（小節線、barline）を曲の進行に合わせてレーン上に流す。
後続のノーツの落下に先立ち、`audioTime` を基準にした表示要素の移動（時刻から奥行き・位置への変換）を、判定に関わらない背景要素で実装する。

## タスク種別
設計・実装

## 要件
- 小節線のコンポーネントを作成する
  - レーン上（レーン全体の幅）に表示する横線とする
  - 背景の要素として、判定バー・（後続の）ノーツより目立たない表示にする
  - 重なり順はレーンの上、判定バーの下とする
- 小節線を曲の進行に合わせて上（レーン上端）から下に流す
  - 小節の頭の時刻に、小節線が判定バーの位置に来るようにする
  - 位置は `audioTime` から求める（フレームごとの移動量を積算しない）
  - レーンの奥行きの表現（`docs/spec/play.md`「奥行きの表現」）に合わせ、奥ほど幅が狭く、間隔が詰まって見えるようにする
  - レーン上端ではレーンと同様にフェードアウトした状態で現れる
  - 判定バーを通過した後は、画面の下端まで流れて消える
  - 表示範囲外の小節線は描画しない
- `Track` に小節の間隔を追加し、それを元に小節線の表示タイミングを決める
  - 値は曲（音源）に対応する情報として Title 側で `Track` を作成する際に設定する
  - 仮の音源 `src/assets/sample.mp3` は 120 BPM・4 拍子（1 小節 2000ms）であり、これに対応する値を設定する
    - 1 小節目の頭は音声の先頭（0ms）と一致する
  - `Track` には BPM と拍子（1 小節の拍数）を持たせ、小節の間隔は計算で求める（leadIn の変更後の型は後述）
    ```typescript
    type Track = {
      // ...既存のフィールド
      /** テンポ（1 分あたりの拍数） */
      bpm: number;
      /** 1 小節の拍数 */
      beatsPerBar: number;
    };
    ```
    - 1 小節の時間 = `60000 / bpm * beatsPerBar`（ms）
    - 理由: 曲の情報として自然で、後続で拍ごとの補助線などに拡張しやすい
    - 最初の小節の頭の時刻（音声の先頭からのオフセット）は持たせず、音声の先頭（0ms）を 1 小節目の頭とする
- leadIn の仕様を変更する
  - leadIn（再生のディレイ時間）は 1 小節の時間とする（仮の音源では 2000ms となり、現状の値と変わらない）
    - テンポの速い曲では leadIn が短くなるが、曲の開始と同時にノーツが来ることは基本的にないため、フェードの時間（400ms）を下回らなければ問題ないとする。実装を見て調整する
  - `Track.leadIn` は削除し、leadIn は `bpm` と `beatsPerBar` から計算で求める
    ```typescript
    type Track = {
      audioContext: AudioContext;
      source: AudioBufferSourceNode;
      /** テンポ（1 分あたりの拍数） */
      bpm: number;
      /** 1 小節の拍数 */
      beatsPerBar: number;
    };
    ```
  - leadIn を参照している既存の処理（Title の再生予約、Play の `audioTime` の計算）を、計算で求めた leadIn を使うように変更する
    - Title の定数 `LEAD_IN`（2000ms）は削除する

## 検討事項（plan.md で決める）
- 流れる速度（小節線がレーン上端から判定バーに到達するまでの時間）の決め方と値
  - 後続のノーツも同じ速度で流れる前提とし、ノーツと共有できる形にする
- 時刻と奥行きの対応（時刻に対して奥行きを線形にするか、など）
  - 既存の `project` / `depthAtY` との関係
- 時刻から位置を求める処理の置き場所（`docs/architecture.md` のゲームロジックの分離方針に従う）
- 1 小節の時間（leadIn）を求める処理の置き場所と、`startTrack` の引数の形
- leadIn の間（`audioTime` が負の間）の扱い
  - 曲の先頭より前の小節線を表示するか

## 実装上の条件
- 既存の表示要素（背景・レーン・判定バー）と曲の再生、開発時の `audioTime` 表示を維持する
- 外部パッケージを追加しない
- 時刻から位置を求める処理は純粋な関数とし、テストを書く

## 検証
- ブラウザで、小節線が曲の進行に合わせて流れること、判定バーの位置と小節の頭の時刻が一致することを確認する
  - 開発時の `audioTime` 表示と合わせて確認する
- Health Check（C1〜C6、task scope）を実行する
- 主要な画面サイズのスクリーンショットを取得・確認する

## 対象外
- ノーツの描画・落下、譜面データの読み込み
- 拍ごとの補助線
- BPM・拍子の途中変更（変拍子・テンポチェンジ）
- 入力と判定、スコア、リザルト
- 出力レイテンシの補正
