# 用語集
プロジェクトの固有概念について、認識を揃えるため、表記揺れを防ぐために作成する

## Stage
9:16 で固定されたゲーム領域
- HTML 要素（div）で構成し、画面サイズに応じて拡大縮小される

## Scene
Stage 上に表示される画面の単位。以下の 2 つがある

- Title: 開始画面
- Play: ゲーム画面

## 論理座標
Scene 内の SVG で用いる座標系
- viewBox `0 0 360 640` で、実際の画面サイズに依存しない

## レーン(lane)
ノーツが流れる縦の通り道。
- 5 本あり、左から 0〜4 の番号で区別する（番号は後続のノーツのタスクで使う想定）

## ノーツ(note/notes)
レーン上に流れる長方形のシンボル。

## 判定バー(judgement bar)
ノーツを叩くタイミングを示す横線。
