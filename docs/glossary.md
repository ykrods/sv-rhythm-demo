# 用語集
プロジェクトの固有概念について、認識を揃えるため、表記揺れを防ぐために作成する

## Stage
9:16 で固定されたゲーム領域
- HTML 要素（div）で構成し、画面サイズに応じて拡大縮小される

## Scene
Stage 上に表示される画面の単位。以下の 2 つがある

- Title: 開始画面
- Play: ゲーム画面

## 論理座標
Scene 内の SVG で用いる座標系
- viewBox `0 0 360 640` で、実際の画面サイズに依存しない

## レーン(lane)
ノーツが流れる縦の通り道。
- レーンは奥行き表現を持たせて描画される
- 5 本あり、左から 0〜4 の番号で区別する

## ノーツ(note/notes)
レーン上に流れる長方形（レーンに奥行きがあるため描画は台形になる）のシンボル。

## 判定バー(judgement bar)
ノーツを叩くタイミングを示す横線。

## 奥行き(depth)
判定バーからの奥方向のレーン上の位置（レーン上端までを 1 とした、単位のない値）
- レーンの上端を 1、判定バーを 0、判定バーより手前は負の値となる
- ノーツや小節線は、その時点での横の位置と奥行きから、透視投影で論理座標を求める（`docs/spec/play.md`「奥行きの表現」）

## 曲(Track)
曲とその関連データの単位 (型は `src/types.ts` 「Track」 を参照)
- 曲の情報（テンポ・拍子・譜面・音源）に加え、再生の状態（`AudioContext` と再生中の音源）も含む
- 再生の状態を含まない曲の情報のみのデータは `TrackData` とする
- 文脈上明らかな場合は、「曲」を単に音源（音声データ・その再生）の意味で用いることもある（例: 「曲の再生」「曲を取得・デコードする」）

## 譜面
曲に対するノーツの集合。
- データとしては `track.notes` のリストが譜面にあたる
