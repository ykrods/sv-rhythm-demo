# play

ゲーム画面（Play Scene）の仕様。
現状は静的な表示要素（背景画像・レーン・判定バー）のみで、ノーツ・入力・判定・スコアなどは未実装。

## 表示要素
座標は論理座標（`docs/spec/layout.md`「論理座標」）で示す。
重なり順は下から背景画像・レーン・判定バーの順とする。

- 背景画像
  - Title と同じく `src/assets/bg.webp` を Scene 全面に表示する（`preserveAspectRatio="xMidYMid slice"`）
  - 画像の読み込みが終わるまでは、暗い紺色（`#0d0b2e`）の下地を表示する
- レーン
  - 5 本のレーンを、奥行きのある表現（手前が広く奥が狭い台形）で表示する（「レーンの形」を参照）
  - 背景は透過ありの濃紺（`#0a0a2e`、不透明度 0.6）で塗る
  - レーンの両端と間に境界線（計 6 本）を引く。色はネオン調の青（`#4fc3ff`）、線幅 1.5 で、発光させる
    - 線幅は奥でも一定とする
- 判定バー
  - 画面の下 2 割の位置（y = 512）に、画面幅いっぱい（x = 0〜360）の横線を表示する
  - 色はレーンと同じネオン調の青（`#4fc3ff`）。レーンの境界線より太く（線幅 3）、発光を強くする

## レーンの形
- 配置

  | 項目 | y | レーン全体の幅 |
  |---|---|---|
  | 上端 | 128（画面の上 2 割） | 90（画面幅の 25%） |
  | 判定バー | 512（画面の下 2 割） | 360（画面幅と一致） |
  | 下端 | 640（画面の最下部） | 450（左右に 45 ずつはみ出し、画面外は表示されない） |

- 各レーンは判定バーの位置で幅 72（画面幅の 5 等分）となり、横の中央（x = 180）に向かって奥ほど狭くなる
- 上端から 96（`SCENE_HEIGHT * 0.15`）の長さで、上に向かってフェードアウトさせる（背景・境界線とも）

### 奥行きの表現
- 透視投影で奥行きを表現する。判定バーの位置を基準に、奥ほど縮小率を小さくする
  - 縮小率 `s = 1 / (1 + 3d)`（d は奥行き。判定バーで 0、レーン上端で 1、判定バーより手前は負の値）
  - 上端（d = 1）で縮小率 0.25、下端で 1.25（d = -1/15）となる
- 消失点は (180, 0)（Scene の上端の中央）
- 判断の経緯は `docs/decisions/002-lane-perspective.md` を参照
