# title

開始画面（Title Scene）の仕様。

## 表示要素
座標は論理座標（`docs/spec/layout.md`「論理座標」）で示す。

- 背景画像
  - `src/assets/bg.webp`（900×1600、9:16）を Scene 全面に表示する（`preserveAspectRatio="xMidYMid slice"`）
  - 画像の読み込みが終わるまでは、暗い紺色（`#0d0b2e`）の下地を表示する
- タイトルロゴ
  - テキスト「sv-rhythm-demo」を Web フォント Orbitron（太字）で表示する
  - 水色から桃色への横方向のグラデーションで塗り、発光させ、少し斜体（`skewX(-10)`）にする
  - 横中央、ロゴの中心の y は Scene の高さの 30%。幅は 300 に揃える（`textLength`）
- スタートボタン
  - グラデーション（青から紫）で塗った角丸の矩形に「START」を表示する。幅 240・高さ 64、横中央、ボタンの中心の y は Scene の高さの 65%
  - ホバー・押下時に明るくする
- 説明文「Press SPACE to start」
  - スタートボタンの下に白字で表示する。横中央、中心の y は Scene の高さの 75%
  - キーボードがありそうな環境（PC）でのみ表示する（「説明文の表示条件」を参照）

## 開始の操作
以下のいずれかでゲーム画面（Play Scene）に遷移する。

- スタートボタンのクリック・タップ
- Space キー（Title の表示中はどこにフォーカスがあっても有効。キーの押しっぱなしによるリピートは無視する）
- スタートボタンにフォーカスがある状態での Enter キー

## 説明文の表示条件
- 端末の種類ではなく入力手段で判別し、CSS のメディアクエリ `(hover: hover) and (pointer: fine)` に当てはまるときだけ表示する
- 完全な判別ではないが、以下の挙動を許容する
  - タッチ対応のノート PC: 主な入力がマウス・トラックパッドと判定され表示される（キーボードがあるので問題ない）
  - キーボードを接続した iPad: 非表示になる（Space での開始は可能）

## Web フォント
- Google Fonts から `index.html` の `<link>` で読み込む（`display=swap`）
- 読み込み前・読み込み失敗時は `sans-serif` で表示する
