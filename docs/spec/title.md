# title

開始画面（Title Scene）の仕様。

## 表示要素
座標は論理座標（`docs/spec/layout.md`「論理座標」）で示す。

- 背景画像
  - `src/assets/bg.webp`（900×1600、9:16）を Scene 全面に表示する（`preserveAspectRatio="xMidYMid slice"`）
  - 画像の読み込みが終わるまでは、暗い紺色（`#0d0b2e`）の下地を表示する
- タイトルロゴ
  - テキスト「sv-rhythm-demo」を Web フォント Orbitron（太字）で表示する
  - 水色から桃色への横方向のグラデーションで塗り、発光させ、少し斜体（`skewX(-10)`）にする
  - 横中央、ロゴの中心の y は Scene の高さの 30%。幅は 300 に揃える（`textLength`）
- スタートボタン
  - グラデーション（青から紫）で塗った角丸の矩形に「START」を表示する。幅 240・高さ 64、横中央、ボタンの中心の y は Scene の高さの 65%
  - ホバー・押下時に明るくする
- 説明文「Press SPACE to start」
  - スタートボタンの下に白字で表示する。横中央、中心の y は Scene の高さの 75%
  - キーボードがありそうな環境（PC）でのみ表示する（「説明文の表示条件」を参照）

## 曲の読み込み
- Title の表示時に、曲（仮の音源 `src/assets/sample.mp3`）を取得・デコードしておく
  - 読み込み中の表示は行わない
- 読み込みに失敗した場合は、次の開始の操作の時点で読み込みをやり直す（「読み込みが完了していない場合」を参照）

## 開始の操作
以下のいずれかで曲の再生を開始し、ゲーム画面（Play Scene）に遷移する。

- スタートボタンのクリック・タップ
- Space キー（Title の表示中はどこにフォーカスがあっても有効。キーの押しっぱなしによるリピートは無視する）
- スタートボタンにフォーカスがある状態での Enter キー

- ブラウザの自動再生の制限を受けないよう、曲の再生は開始の操作のイベントの中で同期的に予約する
  - 曲は開始の操作から leadIn（2000ms）後に再生が始まる。Play の再生位置については `docs/spec/play.md`「曲の再生」を参照
    - 厳密には、音声の再生が一時停止状態から始まる場合は、再生の再開が完了した時点から leadIn 後に再生が始まる。再開は通常数 ms ほどで完了するため、この誤差は許容する
  - iOS では消音スイッチ（マナーモード）の状態に関わらず再生する（`navigator.audioSession` に対応するブラウザのみ）
- 通常は開始の操作で即座に遷移する。ブラウザによって音声の再生が一時停止状態から始まる場合は、再生の再開が完了してから遷移する
- 遷移時の演出は `docs/spec/common.md`「Scene の切り替え」を参照
- 開始の操作を受け付けてから Title が取り除かれるまで（再生の再開待ち・フェード中）に開始の操作を行っても、再生・遷移は再度行われない（曲は多重再生されない）

### 読み込みが完了していない場合
- 曲の読み込み中・読み込み失敗時に開始の操作を行うと、`window.alert` で「読み込みが未完了です」と表示し、Title に留まる
  - 読み込みに失敗していた場合は、読み込みをやり直す
  - 暫定的な挙動であり、今後見直す予定

### 再生の開始に失敗した場合
- 音声の再生の準備（`AudioContext` の作成・再生の予約・再生の再開）に失敗した場合は、`window.alert` で「曲の再生に失敗しました、ブラウザの音声再生の許可設定を確認してください。」と表示し、Title に留まる
- メッセージの表示後は、開始の操作で再試行できる
- ブラウザのタブのミュートなど、エラーにならずに無音で再生される場合は検出しない

## 説明文の表示条件
- 端末の種類ではなく入力手段で判別し、CSS のメディアクエリ `(hover: hover) and (pointer: fine)` に当てはまるときだけ表示する
- 完全な判別ではないが、以下の挙動を許容する
  - タッチ対応のノート PC: 主な入力がマウス・トラックパッドと判定され表示される（キーボードがあるので問題ない）
  - キーボードを接続した iPad: 非表示になる（Space での開始は可能）

## Web フォント
- Google Fonts から `index.html` の `<link>` で読み込む（`display=swap`）
- 読み込み前・読み込み失敗時は `sans-serif` で表示する
