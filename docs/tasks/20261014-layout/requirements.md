# requirements: layout

## 目的
`docs/proposal.md` のマイルストーン 1「画面の骨組み」の実装に着手する。
手始めとして、本タスクでは画面レイアウトのみを実装する。

## タスク種別
実装

## 前提
- `docs/proposal.md`

## やること
- 画面レイアウトの実装
  - ゲーム領域の縦横比を 9:16 で固定する
  - スマホではブラウザの表示領域いっぱい、PC（および横向きのスマホ）では縦長の領域を中央に配置する
    - 縦長すぎる端末では上下に余白が出ることを許容する
  - ゲーム画面は SVG の論理座標（viewBox）で描画し、実際の画面サイズに依存しないようにする
    - viewBox のサイズは 360 × 640 とする
      - 理由: 1 単位がスマホの CSS px とほぼ一致し、フォントサイズや線幅を直感的に指定できる。また 5 レーンで割り切れる（レーン幅 72）
  - タッチ操作時のスクロール・拡大・テキスト選択を抑止する
- 開始画面・ゲーム画面それぞれのレイアウト（骨組み）
  - 表示内容は仮の SVG のみとする（具体的な表示内容は後続タスクで決める）

## やらないこと
- 開始画面からゲーム画面への遷移
- キーボード / タップによる開始操作
- マイルストーン 2 以降の内容（レーン・ノーツの描画、判定、スコア、音声など）
